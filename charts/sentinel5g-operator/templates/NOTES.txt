Sentinel5G operator installed into namespace "{{ .Release.Namespace }}".

Apply a TelecomSecurityPolicy to start protecting a workload, e.g.:

  kubectl apply -f config/samples/security_v1alpha1_telecomsecuritypolicy.yaml

Check status:

  kubectl get telecomsecuritypolicies -A

The SCORING column is whether the AI engine has ever published a score. It
reads False after {{ .Values.config.scoringPipelineGrace }} if the scoring
half of the system isn't running -- the AI engine is a separate chart
(charts/sentinel5g-ai-engine) and is NOT installed by this one:

  helm install sentinel5g-ai-engine charts/sentinel5g-ai-engine -n {{ .Release.Namespace }} \
    --set nats.url={{ .Values.nats.url }}

Without it every policy sits at Phase: Monitoring forever, and until the
SCORING column existed that looked identical to a healthy, quiet cluster.
